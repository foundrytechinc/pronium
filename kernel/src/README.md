## Using Pronium OS

If you wish to use Pronium OS for your daily operations and tasks, you do **not** need to compile this kernel. The operating system is officially distributed as a pre-built, ready-to-use bootable blob (the `.iso` image). Please download (getpronium.su) and use the official `.iso` releases for full functionality.

For detailed information about the system architecture (such as POS, PDF, FAT32 IPC, and the user shell), please refer to the offical site getpronium.su
